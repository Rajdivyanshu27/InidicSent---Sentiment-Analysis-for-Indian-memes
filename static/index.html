Supported Tasks & Architecture
  • Task A — Sentiment Analysis: Classifies memes into Positive, Negative, or Neutral using TF-IDF (word + char n-grams), MobileNetV2 visual embeddings, CV visual stats, Dual-Branch Neural Nets, Logistic Regression, and XGBoost.
  • Task B — Multi-Label Emotion Classification: Detects Humorous, Sarcastic, Offensive, and Motivational signals simultaneously.
  • Task C — Emotion Intensity Scales: Quantifies emotion strength (0–3 for Humour/Sarcastic/Offensive, 0–1 for Motivational) with Task B↔C consistency enforcement.
  • Multi-Pass Meme OCR: Upscaled, sharpened, and high-contrast Windows Media OCR automatically extracts meme captions on upload, editable inside the Detected Text drawer.
